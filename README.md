## สิ่งที่อยู่ใน repo

| โฟลเดอร์ / ไฟล์ | เนื้อหา |
|---|---|
| `src/` | แอปวิเคราะห์ (ปริมาณ, คิว, ผายปาก, สัญญาณไฟวงกลม) |
| `src/data/survey.json` | ปริมาณและคิวที่ถอดจากไฟล์สำรวจดิบ |
| `attachments/` | ไฟล์ต้นทางที่ส่งมาวิเคราะห์ (xlsx, แบบผายปาก, แผ่นติดตั้ง) |
| `public/docs/laksi-500-intersection-oa.docx` | รายงาน Word ฉบับสมบูรณ์ |
| `scripts/build-te-report-docx.py` | สคริปต์สร้างไฟล์ Word จากข้อมูลดิบ |

## วิธีรัน

```bash
npm install
npm run dev
```

เปิด `http://localhost:8080` — ปุ่ม **Word** มุมขวาบนคือไฟล์รายงาน

```bash
npm run typecheck
npm run build
```

สร้าง Word ใหม่จากข้อมูลดิบ:

```bash
pip install python-docx
python3 scripts/build-te-report-docx.py
```

## แหล่งข้อมูลดิบ

- `หลักสี่(500) 69_05_20.xlsx` — สำรวจ 20 พฤษภาคม 2569
- แบบผายปากแยกหลักสี่
- แผ่นติดตั้งคอนโทรลเลอร์ ศรีทองเจริญ ตู้ 500
